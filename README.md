# NotionAI Terminal Connect

Временный защищённый MCP-мост между Notion AI и терминалом Linux. Пока скрипт запущен, Notion AI может читать и менять файлы проекта, запускать команды, тесты и длительные процессы, а затем получать их вывод.

После `Ctrl+C` локальный сервер, публичный туннель и управляемые им процессы завершаются. При следующем запуске создаются новый URL и новый токен.

> [!WARNING]
> Это намеренно мощный инструмент. Команды выполняются с правами локального пользователя и **не изолированы файловой песочницей**. Не запускайте мост через `sudo`. Для недоверенного кода используйте отдельную VM или контейнер.

## Быстрый запуск

Требования:

- Linux x86-64, ARM64 или ARMv7;
- Node.js 20+ и npm;
- `curl` или `wget`, если `cloudflared` ещё не установлен.

```bash
git clone https://github.com/talex00/NotionAI-terminal-connect.git
cd NotionAI-terminal-connect
bash start.sh ~/projects/my-project
```

Первый запуск установит npm-зависимости и скачает `cloudflared` в локальный каталог `.runtime/bin`, если его нет в системе. Никакая системная служба не создаётся.

Без аргумента открывается текущий каталог:

```bash
bash start.sh
```

После запуска появится блок такого вида:

```text
Notion AI terminal bridge is ready
Workspace:      /home/user/projects/my-project
MCP Server URL: https://random-words.trycloudflare.com/mcp
Authentication: Bearer token
Token:          <temporary-random-token>
```

## Подключение к Notion AI

1. Откройте в Notion добавление пользовательского MCP-подключения.
2. Вставьте значение `MCP Server URL`.
3. Выберите авторизацию с Bearer token.
4. Вставьте временный `Token` в поле токена подключения.
5. Оставьте терминал со скриптом открытым.

Название пунктов интерфейса может отличаться в разных версиях Notion. Токен не нужно отправлять в чат, сохранять в `.env` или коммитить.

Для отключения нажмите `Ctrl+C` в терминале. Quick Tunnel перестанет существовать, токен станет бесполезен, а следующий запуск выдаст другие реквизиты.

## Доступные MCP-инструменты

| Инструмент | Назначение |
|---|---|
| `workspace_info` | Показывает корень проекта и границы безопасности |
| `list_directory` | Выводит дерево файлов, не переходя по симлинкам |
| `read_file` | Читает часть файла как UTF-8 или base64 |
| `write_file` | Создаёт, перезаписывает или дополняет файл |
| `replace_in_file` | Делает точную замену с проверкой числа совпадений |
| `make_directory` | Создаёт каталог внутри workspace |
| `terminal_execute` | Запускает команду и возвращает stdout, stderr и exit code |
| `process_start` | Запускает управляемый длительный процесс |
| `process_status` | Показывает состояние и накопленный вывод процесса |
| `process_list` | Перечисляет управляемые процессы |
| `process_stop` | Завершает группу процессов |

Файловые инструменты отклоняют пути вне выбранного workspace и переходы наружу через существующие символические ссылки.

Команды терминала запускаются в выбранном workspace через `/bin/bash -lc`, но работают от имени пользователя, запустившего мост. Поэтому команда с абсолютным путём или `../` может получить доступ за пределами workspace, если у пользователя есть соответствующие права.

## Примеры

Выбрать каталог и локальный порт:

```bash
bash start.sh --workspace ~/code/app --port 8765
```

Использовать уже установленный `cloudflared`:

```bash
bash start.sh --cloudflared /usr/local/bin/cloudflared ~/code/app
```

Посмотреть параметры:

```bash
bash start.sh --help
```

## Настройки окружения

| Переменная | По умолчанию | Описание |
|---|---:|---|
| `MCP_WORKSPACE` | текущий каталог | Корень файловых инструментов и стартовый cwd |
| `MCP_PORT` | свободный порт | Локальный порт сервера |
| `MCP_SHELL` | `/bin/bash` | Shell для команд |
| `MCP_COMMAND_TIMEOUT_MS` | `120000` | Таймаут обычной команды |
| `MCP_MAX_COMMAND_TIMEOUT_MS` | `900000` | Максимально разрешённый таймаут |
| `MCP_MAX_OUTPUT_BYTES` | `1000000` | Лимит stdout/stderr на поток |
| `MCP_MAX_FILE_BYTES` | `5000000` | Лимит одной файловой операции |
| `CLOUDFLARED_BIN` | авто | Путь к `cloudflared` |
| `MCP_ALLOW_ROOT` | `0` | Разрешить запуск от root; только для изолированного контейнера |

## Как это устроено

```text
Notion AI
    │ HTTPS + Bearer token
    ▼
Cloudflare Quick Tunnel (временный URL)
    │
    ▼
127.0.0.1:<случайный порт>/mcp
    │
    ├── файловые операции внутри workspace
    └── команды и управляемые процессы от имени локального пользователя
```

MCP-сервер слушает только loopback-интерфейс. Наружу его публикует временный Cloudflare Quick Tunnel. Сервер проверяет случайный 256-битный токен в каждом MCP-запросе.

Quick Tunnels удобны для временных сессий разработки, но не имеют гарантий доступности и не предназначены для постоянного production-развёртывания.
